# Apna Ghar Fix Vala (AGFV) — Official Promotional Website

A high-converting, mobile-first, and blazing-fast promotional & instant booking website built for **Apna Ghar Fix Vala (AGFV)**.

Designed specifically for marketing campaigns (Google Ads, Meta Ads, WhatsApp Status & broadcast flyers) to maximize lead conversion into instant WhatsApp bookings.

---

## 🚀 Key Features

1. **Direct WhatsApp-First Booking Integration**:
   - 1-Click WhatsApp booking pre-populating customer choice, service, city, area, and promo code directly to the business WhatsApp number `+91 9460809860`.
   - Floating interactive WhatsApp support bubble with live ping.
   - Sticky mobile action bar (Call + WhatsApp Booking).

2. **Interactive Promotional Engine**:
   - Live Countdown Timer for limited-time offers.
   - Promotional Coupon Codes:
     - `AGFV20`: Flat 20% OFF on all services.
     - `ACCOOL150`: ₹150 OFF AC Jet Servicing.
     - `HOMECARE`: ₹250 OFF combo bookings.
     - `FIRST100`: ₹100 Flat discount.
   - 1-Click "Copy Code" with toast notification feedback.

3. **Interactive Rate Estimator & Calculator**:
   - Customers can select Service Category (AC, Plumbing, Electrical, Carpentry, Washing Machine, Refrigerator, Cleaning, Pest Control).
   - Dynamic quantity adjuster and live discount calculator.
   - Transparent comparison between Apna Ghar Fix Vala vs. Unverified local technicians.

4. **Service Coverage & Pincode Lookup**:
   - Interactive locality & pincode checker for Mumbai MMR and Pune PCMC with instant confirmation badge.

5. **Visual Excellence & High Conversion UI**:
   - Built with modern Google Fonts (*Plus Jakarta Sans* & *Outfit*).
   - Commercial advertising-grade photography for AC service, plumbing, and verified technicians.
   - Rich glassmorphism panels, CSS micro-animations, and fast loading with 0 runtime dependencies.

6. **SEO & Social Share Ready**:
   - Structured JSON-LD schema for LocalBusiness & AggregateRating.
   - OpenGraph and Twitter card meta tags for rich link previews on WhatsApp and social media.

---

## 🛠️ Technology Stack

- **Core Structure**: Semantic HTML5 with accessibility tags and Schema.org markup.
- **Styling**: Modern Vanilla CSS with CSS custom property tokens, flexible grids, and mobile-first responsive breakpoints.
- **Interactive Logic**: Vanilla JavaScript (ES6+) for calculations, clipboard API, and URL-encoded WhatsApp deep links.
- **Deployment**: Ready for Vercel, Netlify, or GitHub Pages.

---

## 🌐 Local Development

To run the site locally:

```bash
# Using any static server, e.g. Node serve:
npx serve .

# Or Python 3:
python -m http.server 3000
```

Open `http://localhost:3000` in your browser.

---

## 📦 Deployment to Vercel

```bash
npx vercel --prod
```
